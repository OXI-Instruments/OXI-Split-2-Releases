# OXI Split 2 firmware releases

Firmware for the OXI Split 2, published as SysEx (`.syx`) files.

Download the latest file from [Releases](https://github.com/OXI-Instruments/OXI-Split-2-Releases/releases).

## How to update

1. Unplug the OXI Split 2 from the OXI One.
2. Hold the button on the OXI Split 2 and plug it into the OXI One's Split port.
3. In the OXI App, start the OXI Split update and send the `.syx` file.
4. When the update ends, check the Split's outputs A–F.
